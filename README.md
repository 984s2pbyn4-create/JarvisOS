# JARVIS OS — iPad Edition v0.1.0

**Статус:** рабочая первая версия командного центра, рассчитанная в первую очередь на iPad и Safari. Это НЕ законченная версия 1.0 и НЕ операционная система iPadOS.

## Что работает

- Адаптивный домашний экран и футуристический интерфейс с тремя цветовыми темами.
- Сенсорная навигация, нижний dock, модульные экраны и быстрый поиск по приложениям.
- Заметки с автосохранением в IndexedDB.
- Задачи: создать, отметить выполненной, удалить.
- Локальные файлы: импорт, скачивание, удаление в IndexedDB.
- Audio Lab: загрузка локального аудиофайла, воспроизведение, частотный анализ через Web Audio при поддержке браузера.
- Калькулятор, часы, диагностика возможностей браузера.
- Резервное копирование и восстановление через JSON (файлы >15 МБ исключаются из резервной копии).
- PWA manifest, иконки, service worker для автономной загрузки после первого успешного открытия.
- GitHub Actions для автоматической публикации.

## Что ещё не реализовано

- Многопанельный менеджер окон с drag-and-drop, синхронизация устройств, расширяемый App SDK, 3D-модули, ИИ-чат, импорт СКАТ/СКиП.
- Настоящее голосовое управление: есть пробный ввод через SpeechRecognition, который доступен не во всех браузерах и не всегда офлайн.
- Шифрование локального хранилища и защита данных паролем. **Не сохраняйте в приложении секретные данные**.

## Установка на GitHub Pages

> Рекомендуемый вариант: репозиторий с именем `jarvis-os-ipad`. Можно выбрать другое имя: в этом проекте все ссылки относительные.

1. Создайте новый **public** repository на github.com. Не добавляйте автоматический README (здесь есть свой).
2. Распакуйте `JARVIS_OS_iPad_v0.1.zip` в приложении «Файлы» на iPad. ZIP целиком загружать в репозиторий бессмысленно: GitHub не разархивирует его автоматически.
3. Поместите **содержимое** папки `JARVIS_OS_iPad_v0.1`, а не внешнюю папку, в корень репозитория. Важно сохранить вложенные каталоги `src/`, `assets/` и `.github/workflows/`.
4. GitHub → Settings → Pages → Build and deployment → Source: **GitHub Actions**. При push в `main` workflow автоматически публикует приложение.
5. Откройте адрес `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

**Альтернативный простой вариант:** Settings → Pages → Deploy from a branch → `main` / `(root)`. Для этого проекта он тоже подходит: сборка npm не нужна. Если публикация через Actions вызывает затруднения, используйте этот вариант.

### Установка на iPad

1. Откройте опубликованный HTTPS-сайт в **Safari**.
2. Нажмите «Поделиться» → «На экран Домой» (иногда пункт находится в «Ещё»).
3. Активируйте «Открывать как веб-приложение», если переключатель виден.
4. Нажмите «Добавить» и открывайте JARVIS через иконку на экране «Домой».
5. После первого полного запуска попробуйте включить авиарежим и открыть приложение повторно. Работа офлайн зависит от сохранённого браузером кэша.

## Разработка локально

Сторонние библиотеки и npm не требуются. ES-модули не запускаются надёжно с `file://`, поэтому открывайте через локальный HTTP-сервер:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Секретные ключи и личные файлы в репозиторий не помещать: всё опубликованное на GitHub Pages потенциально публично. Документы хранятся только в браузерной IndexedDB на конкретном устройстве и не загружаются в GitHub.

## Архитектура

- `index.html` — точка входа.
- `styles.css` — интерфейс и адаптивная сетка.
- `src/app.js` — shell, каталог приложений, управление экранами, события, функциональность модулей.
- `src/db.js` — IndexedDB и резервные копии.
- `src/icons.js` — встроенные SVG-иконки.
- `sw.js` — офлайн кеш по относительным путям.
- `manifest.webmanifest` — установка на домашний экран.
- `.github/workflows/deploy.yml` — публикация через GitHub Actions.

Платформа поддерживает только **доверенные встроенные модули**. Произвольный пользовательский JavaScript не исполняется. Для дальнейшей разработки целесообразно разнести модули по отдельным файлам и добавить API разрешений, App Registry и e2e-тесты в Safari/WebKit.

## Ограничения

- Safari может очистить локальное хранилище. Для важных заметок используйте «Настройки → Экспорт» и сохраняйте резервную копию в «Файлы».
- Нет доступа к EXE, к защищённым областям iPadOS или Windows.
- Приложение работает без сервера только после первой загрузки. GitHub Pages необходим для публикации/обновления.
- Это оригинальный интерфейс, без графических материалов Marvel.
