# План развития iPad-версии

## Сделано в v0.1 (текущий архив)

PWA shell, offline app shell, module catalog, touch-first UI, command search, notes, tasks, file vault, audio, calculator, clock, diagnostics, settings and backup/restore.

## v0.2 — надёжность и опыт iPad

- Поддержка двух одновременных панелей в альбомной ориентации и вкладок с независимыми состояниями.
- Клавиатурные сочетания, контекстное меню долгим нажатием, жесты с доступными альтернативами.
- Проверка реального Safari iPadOS и автоматические e2e-тесты WebKit.
- Улучшения хранилища: квоты, предупреждения, экспорт больших файлов и миграции БД.

## v0.3 — App SDK

- `AppRegistry`, типизированный интерфейс плагинов и разрешения.
- Внутренние событийные команды, sandbox для недоверенных iframe, обработка ошибок.
- Миграция кодовой базы на TypeScript с тестами модулей. Выбор фреймворка после профилирования на iPad.

## v0.4 — интерактивность

- Отложенно загружаемый 3D HUD, оптимизированный для iPad GPU.
- Расширенные возможности Sound Lab (RMS, пики, спектр).
- Интерактивное управление планировкой, если пользователь предоставит исходные данные.

## v0.5 — Intelligence

- Натуральные команды без ИИ, доступные полностью локально.
- Экспериментальный локальный ИИ при поддержке устройства и выделенного объёма памяти.
- Опциональные облачные модели только с безопасным API proxy и явным согласием пользователя.

## Версия 1.0 — критерии

- Проверенная PWA офлайн; без потери пользовательских данных при обычных обновлениях.
- Протестированы портрет/ландшафт iPad, ввод касанием и с внешней клавиатуры.
- Рабочие модули, безопасный экспорт/импорт, регистрация приложений.
- Документация, CI, доступность, восстановление после сбоев и стабильные миграции.
