JARVIS OS iPad Edition v1.1.0 · HOLO DECK · EASY UPLOAD

ДЛЯ ОБНОВЛЕНИЯ ДЕЙСТВУЮЩЕГО JARVIS 1.0:
1. В текущей JARVIS выберите «Настройки → Экспорт» и сохраните резервную копию в «Файлы».
2. Распакуйте этот ZIP в «Файлы» на iPad.
3. В существующем GitHub-репозитории JARVIS в корне: Add file → Upload files → добавьте ВСЕ файлы этой папки, НЕ сам ZIP.
4. Замените совпадающие файлы (index.html, app.js, styles.css, sw.js и прочие), нажмите Commit changes.
5. Дождитесь публикации Pages. Полностью закройте веб-приложение JARVIS и запустите снова.
6. Убедитесь, что сверху отображается V1.1.0. На главной появился большой блок HOLO DECK.
7. Откройте: Нейроядро → Солнечная система → Музыкальный реактор → Аркада: перехват.

Если ваш index.html использует './src/app.js', НЕ загружайте эти плоские файлы: используйте Source ZIP с сохранением папок.
Если ваш index.html использует './app.js', Easy Upload подходит. Не смешивайте форматы.

ВАЖНО: голосовой режим оставлен без изменений, база данных IndexedDB и формат резервной копии не менялись.
Не удаляйте JARVIS с главного экрана и не очищайте Safari до проверки сохранности данных.
HOLO DECK не использует микрофон. Загруженное аудио обрабатывается локально на устройстве.
