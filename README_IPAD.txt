JARVIS OS 1.2.0 · MISSION CONTROL · iPad Easy Upload

1. В JARVIS v1.1 откройте Настройки → Экспорт и сохраните копию ваших данных в «Файлы».
2. Распакуйте ZIP в iPad «Файлы», затем откройте существующий репозиторий GitHub JARVIS.
3. В корне репозитория выберите Add file → Upload files и загрузите ФАЙЛЫ ИЗ ПАПКИ, а не ZIP.
4. Замените одноименные файлы. Commit changes. GitHub Pages не перенастраивайте.
5. Закройте JARVIS через переключатель приложений и откройте снова. Проверьте v1.2.0.
6. С главного экрана нажмите «ВОЙТИ В MISSION CONTROL».
7. Выберите сектор, поставьте тягу от 55%, нажмите «Гиперпрыжок», затем «Сканировать».

ВАЖНО: Используйте этот вариант, только если прежний index.html обращается к ./app.js.
Если там ./src/app.js, используйте Source ZIP с сохранением вложенных папок.
Никогда не загружайте резервную копию с персональными данными в публичный GitHub.
Не удаляйте иконку старого PWA и не очищайте Safari, пока данные не проверены.
В новой сцене полностью процедурная вымышленная космическая графика, не реальная телеметрия.
Голосовой режим не изменен, микрофон для Flight Bridge не используется.
