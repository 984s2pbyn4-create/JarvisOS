JARVIS OS 2.1.0 — APP HUB / iPad Easy Upload

Все файлы этой папки следует загрузить в КОРЕНЬ существующего репозитория GitHub Pages.
Загружайте файлы, не сам ZIP. Используйте один тип структуры: либо EasyUpload в корне,
либо Source ZIP с папками src/ и assets/. Не смешивайте пути при обновлении.

1. Сначала в JARVIS откройте Настройки → Экспорт и сохраните резервную копию.
2. Скачайте ZIP, распакуйте в «Файлы» на iPad.
3. GitHub → ваш репозиторий → Add file → Upload files → выберите файлы из папки.
4. Замените прежние и сделайте Commit changes.
5. После публикации Pages полностью закройте JARVIS, затем откройте снова.
6. Найдите APP HUB: карточки СКиП и СКАТ ждут настоящих URL GitHub Pages.
7. В карточке нажмите «Подключить», вставьте опубликованный https://...github.io/.../.
8. Для обычного запуска выбирайте «Отдельно в Safari». Для другого домена можно
   попробовать «В окне JARVIS»; некоторые сайты запрещают встраивание.
9. Команды: «Открой СКиП», «Открой СКАТ», «Открой мои приложения».

Если GitHub Pages работает со структурой src/ + assets/, используйте Source ZIP.
JARVIS не загружает ваши приложения с GitHub автоматически, не имеет доступа
к учётной записи GitHub, не делает сторонние сайты офлайн и не сохраняет пароли.
Не очищайте данные Safari и не удаляйте старую PWA до проверки копий.
