JARVIS OS iPad 2.0.0 | EASY UPLOAD
===================================
Папок нет. Все файлы этого архива необходимо загрузить в КОРЕНЬ того же репозитория GitHub Pages.
Прежде чем обновлять, в JARVIS выполните Настройки -> Экспорт и сохраните резервную копию в «Файлы».
1. Распакуйте ZIP в приложении «Файлы» на iPad.
2. В GitHub откройте ваш существующий репозиторий -> Add file -> Upload files.
3. Загрузите содержимое этой папки (НЕ сам ZIP) в корень, где находится index.html.
4. Замените файлы с совпадающими именами и нажмите Commit changes.
5. После публикации закройте старое веб-приложение через переключатель и заново откройте.
6. Проверьте VERSION 2.0.0, существующие заметки, JARVIS Intelligence, DATA ATLAS, Сценарии.
Внимание: GitHub Pages должен оставаться по прежнему URL, иначе браузерные данные могут быть недоступны.
Если ваш GitHub index.html ссылается на ./src/app.js, используйте SOURCE ZIP вместо Easy Upload.
Не удаляйте иконку PWA и не очищайте Safari до проверки резервной копии.
Не загружайте резервные копии с личными файлами в публичный GitHub.
Возможности: локальный сценарный интеллект, брифинг, создание задач/заметок, персональные сценарии, интерактивная карта данных, 3D/Canvas HUD, сохранённые функции 1.2.
Голосовой режим без изменения: система iPadOS иногда задерживает индикатор микрофона.
Для полноценных свободных бесед с генеративным ИИ понадобится отдельный защищённый сервер: GitHub Pages не выполняет серверный код.
