JARVIS OS iPad Edition v1.0.0 · EASY UPLOAD

1. В текущей установленной JARVIS: Настройки → Экспорт. Сохраните копию в «Файлы».
2. Распакуйте ZIP в приложении «Файлы».
3. Откройте ВАШ существующий GitHub-репозиторий JARVIS, где уже работает версия 0.2.3.
4. В корне репозитория: Add file → Upload files → выберите ВСЕ файлы из этой папки.
5. Замените одноимённые файлы (index.html, app.js, db.js, и т. д.); нажмите Commit changes.
6. Дождитесь публикации GitHub Pages. Закройте JARVIS через переключатель приложений iPad и снова откройте с экрана «Домой».
7. Проверьте надпись V1.0.0, старые заметки, задачи и новые Календарь, Проекты, Фокус, Поиск.

ВАЖНО:
- Это FLAT/EASY версия, все 14 файлов приложения находятся в корне, плюс этот текстовый README.
- Не загружайте ZIP как один файл.
- Если в вашем репозитории версия с папками src/ и assets/ и именно на них указывает index.html, используйте Source ZIP с сохранением папок.
- Не удаляйте значок JARVIS с главного экрана и не очищайте Safari до проверки сохранности данных.
- Для первой установки Settings → Pages → Deploy from branch → main → /(root). Если сайт уже работает, настройки менять не нужно.
- Резервные копии содержат личные записи, не публикуйте их на GitHub.
- Голосовой ввод оставлен в стабильном режиме предыдущей версии.
