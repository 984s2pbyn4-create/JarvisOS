JARVIS OS — iPad Edition v0.2.0 (Easy Upload)

1. Сначала в установленной v0.1 откройте Настройки → Экспорт и сохраните JSON резервной копии.
2. Распакуйте этот ZIP в приложение «Файлы» на iPad.
3. Откройте ТОТ ЖЕ репозиторий GitHub, где уже работает JARVIS OS.
4. Add file → Upload files. Загрузите ВСЕ файлы из распакованной папки В КОРЕНЬ репозитория (не ZIP и не папку целиком).
5. Подтвердите замену одноименных файлов, затем Commit changes.
6. Настройки GitHub Pages НЕ МЕНЯЙТЕ, если сайт уже работает.
7. Откройте старый адрес JARVIS OS в Safari. Проверьте надпись V0.2.0.
8. Если осталась старая версия, обновите сайт и закройте/откройте веб-приложение еще раз.
9. Проверьте заметки и задачи, не очищайте данные Safari.

Новые файлы, обязательные для v0.2: commands.js и hologram.js.
Старые каталоги src/ и assets/ из прежнего репозитория можно НЕ удалять: новый index.html использует корневые файлы.
При использовании вложенной структуры берите другой архив Source, а не этот.

Голосовое распознавание зависит от Safari и может не работать офлайн.
Полноценного ИИ и системного доступа к iPadOS нет.
