JARVIS OS iPad 3.0.0 — SPATIAL FORGE

Это архив EASY UPLOAD: все файлы лежат в корне.

ОБНОВЛЕНИЕ
1. В JARVIS 2.1.1 сделайте Настройки → Экспорт. Сохраните резервную копию в «Файлы» на iPad. Не публикуйте копию в GitHub.
2. Распакуйте этот ZIP. Откройте существующий репозиторий JARVIS на GitHub.
3. Загрузите ВСЕ файлы в корень репозитория (не ZIP), замените одноимённые, сделайте Commit changes.
4. Дождитесь GitHub Pages, откройте сайт в Safari, затем перезапустите PWA с главного экрана.
5. Проверьте V3.0.0, заметки, APP HUB, модуль SPATIAL FORGE.

Если нынешний index.html указывает на ./src/app.js, используйте другой архив: Source ZIP.
Не удаляйте установленный JARVIS с главного экрана и не очищайте Safari.

ДОСТУПНЫЕ РЕЖИМЫ
ENGINEERING LAB: касание — выделение, свайп — вращение, два пальца — масштаб, ползунок — разборка, импорт OBJ.
SMART SPACE: демонстрационная комната с диваном, островом, шторами, светом. Это НЕ ваша точная планировка.
KNOWLEDGE UNIVERSE: связи ваших локальных записей JARVIS.
AR PROJECTOR: два USDZ-образца; если AR не открывается из PWA, повторите через Safari.
GESTURE ENGINE: включается отдельно с разрешением камеры; MediaPipe загружается из интернета.

Общее: все встроенные сцены работают без сети после установки; камера-жесты требуют сети для MediaPipe; экспорт/импорт JARVIS включает настройки Spatial Forge.
Установка этого обновления НЕ очищает прежние заметки и ссылки APP HUB.

Все функции камеры и AR требуют проверки на реальном iPad.
