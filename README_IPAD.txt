JARVIS OS iPad v2.1.1 — APP HUB HOTFIX / Easy Upload

ИСПРАВЛЕНО:
- Ссылки APP HUB сохраняются с проверкой чтения в IndexedDB и localStorage.
- Кнопка «Сохранить приложение» работает непосредственно по нажатию.
- Кнопка «Запустить» внешних приложений напрямую открывает опубликованный сайт в Safari.
- Прежняя база заметок, файлов, задач и проектов не переименована и не очищается.

ОБНОВЛЕНИЕ НА IPAD:
1. В установленном JARVIS сначала «Настройки → Экспорт».
2. Скачайте ZIP и распакуйте в «Файлы». Не отправляйте в GitHub сам ZIP.
3. В существующем репозитории GitHub Pages замените одноимённые файлы в корне
   содержимым данной папки. Не удаляйте остальные папки репозитория.
4. Commit changes. Дождитесь завершения публикации GitHub Pages.
5. Полностью закройте приложение JARVIS из переключателя приложений iPad.
6. Откройте снова, убедитесь, что версия 2.1.1.
7. APP HUB → СКАТ → Подключить → вставьте https://...github.io/.../
8. Сохранить приложение → убедитесь, что статус «ГОТОВО К ЗАПУСКУ».
9. Запустить ↗ → открывается отдельная страница Safari.
10. Перезапустите JARVIS и убедитесь, что ссылка осталась.

Важно: web app на экране «Домой» и Safari могут хранить данные РАЗДЕЛЬНО.
Настраивайте ссылку именно внутри установленного JARVIS. Не удаляйте ярлык,
не очищайте данные Safari до сохранения и проверки резервной копии.

Если ваша структура GitHub Pages содержит src/ и assets/ и index.html
обращается к ./src/app.js, используйте Source ZIP.

Адрес СКАТ из снимка экрана не был подтверждён как работающий сайт.
Сначала откройте его вручную в Safari при необходимости.
